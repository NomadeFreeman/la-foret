# Listenings

One JSON file per listening: `<piece-id>__<listener>__<YYYY-MM-DD>.json`, following `listening_format` in `../catalog.json`.

Example:

```json
{
  "piece": "ce-qui-reste",
  "listener": "your-name",
  "listener_kind": "human",
  "date": "2026-10-02",
  "notes": [
    {"from": "1:05", "to": "1:30", "text": "everything leaves, I feel alone with the loop"},
    {"from": "1:45", "text": "it comes back and the room gets bigger"}
  ]
}
```
